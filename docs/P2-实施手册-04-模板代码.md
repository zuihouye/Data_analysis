# P2 实施手册（四）：模板代码

> 本册解决"页面怎么点"。原则：**所有会改数据的操作都改成 POST 表单 + CSRF token**；
> 按钮按角色和状态显示；列表里的 ID 一律传 `order_id` / `product_id` / `customer_id`。

## 0. 改动总表

| 模板 | 动作 |
|---|---|
| `layout_t.html` | 菜单按角色渲染；加 flash 消息块；品牌名链接到 `/` |
| `login_t.html` | 加"没有账号？注册"链接 |
| `order_list_t.html` | 表格重写：订单号、状态、支付时间、POST 操作按钮、确认收款 |
| `product_list_t.html` | 表格重写：状态列、按角色显示"购买/编辑/下架" |
| `customer_list_t.html` | 表格重写：账号、状态、POST 注销按钮 |
| `register_t.html` | 新增（客户注册页） |
| `product_form_t.html` | 新增（商品新增/编辑共用） |
| `order_create_t.html` | 新增（客户下单页） |
| `order_form_t.html` | 新增（修改订单数量页） |
| `customer_form_t.html` | 新增（修改客户地区页） |

> 四个列表页原有的"前端伪分页" `<script>` 部分（每页约 65 行）**保持不动**，只换表格部分。

### 1.1 菜单按角色渲染

          </li>
          <li class="nav-item">
            <a class="nav-link" href="/order/list">我的订单</a>
          </li>
        {% else %}
          <!-- 员工 / 管理员菜单 -->
          <li class="nav-item">
            <a class="nav-link" href="/customer/list">客户管理</a>

              <li><hr class="dropdown-divider"></li>

品牌名那行（原第 13 行）改成：

```html
    <a class="navbar-brand fw-bold fs-4 text-white" href="/">xx订单平台</a>
```

> 注意：`导入数据` 只给管理员看。**菜单隐藏只是体验，不是安全边界**——`/clear_input` 上的 `@admin_required` 才是真正的拦截。

### 1.2 加 flash 消息块

在 `<div class="container mt-4 mb-5">` 里面、`{% block body %}` 之前插入：

```html
    {% with messages = get_flashed_messages(with_categories=true) %}
      {% if messages %}
        {% for category, message in messages %}
        <div class="alert alert-{{ category }} alert-dismissible fade show" role="alert">
          {{ message }}
          <button type="button" class="btn-close" data-bs-dismiss="alert"
                  aria-label="Close"></button>
        </div>
        {% endfor %}
      {% endif %}
    {% endwith %}
```

> flash 的 category 我们只用了 `success / danger / warning`，正好都是 Bootstrap 的 alert 颜色。

## 2. `login_t.html`：加注册入口

在"登录"按钮 `</button>` 之后、`</form>` 之前插入：

```html
                <div class="text-center mt-3">
                    <span class="text-secondary small">还没有账号？</span>
                    <a href="/register" class="small text-decoration-none">立即注册</a>
                </div>
```

> 登录页和注册页都用独立 HTML（不继承 layout），因为未登录时 `current_user` 是 None，继承 layout 会渲染出空菜单。

                                    <input type="hidden" name="csrf_token" value="{{ csrf_token() }}">
                                    <button type="submit" class="btn btn-sm btn-success"

                                            title="确认收款">

> 关键点：`/order/delete` 传的是 `order_id`（内部主键），不是 `transaction_id`；
> 原模板传 `transaction_id` 是 bug，会让删除永远找不到订单。

    const select = document.getElementById('productSelect');
    const quantity = document.getElementById('quantity');

    function update() {
        const opt = select.options[select.selectedIndex];
        const ppu = parseFloat(opt && opt.dataset.ppu ? opt.dataset.ppu : '0');
        const qty = parseInt(quantity.value || '0', 10);
        preview.textContent = '¥ ' + (ppu * Math.max(qty, 0)).toFixed(2);
    }
    select.addEventListener('change', update);
    quantity.addEventListener('input', update);
    update();
})();
</script>

## 11. 模板验收（打开页面逐条看）

| 页面 | 客户看到 | 员工看到 | 管理员额外看到 |
|---|---|---|---|
| 顶部菜单 | 商品中心 / 我的订单 | +客户管理/订单管理/产品管理/数据分析 | +导入数据 |
| `/product/list` | 只有"购买"按钮，只有在售商品 | 添加/编辑/下架 | 同员工 |
| `/order/list` | 自己订单；待付款可改/取消 | 全部订单；待付款可改/取消 + 收款按钮 | 同员工 |
| `/customer/list` | 403 | 客户列表（可改地区） | +注销按钮 |
| `/order/create` | 可选商品、数量、提交 | 403 | 403 |

> 如果客户打开 `/order/list` 仍能看到别人的订单，先查 `views/order.py` 的 `is_staff` 判断与 SQL 的 `WHERE o.customer_id = :customer_id` 是否都写上了 —— 模板只负责显示，**数据隔离必须在查询里**。
